# WP8F · Warthunder Port 8111 Frontend

<img src="gui/static/logo.svg" alt="wp8f" width="80" align="right">

**WP8F（Warthunder Port 8111 Frontend）** 是战争雷霆的飞行数据 HUD。把游戏里的飞行数据
（速度、高度、攻角、过载、发动机、油量……）变成一块透明的仪表盘，叠加在屏幕上；
顺带提供配置、飞行记录回放、飞机性能曲线和数据链。

## 与 VoidMei 的关系

WP8F 是 [VoidMei](https://github.com/matrixsukhoi/voidmei) 的**全面重构升级版**（两者同作者）：
思路一脉相承 —— 读取游戏开放的 8111 端口，把飞行数据叠加到游戏画面上 —— 而代码、架构与实现
**整体重写**，在性能、功能、安全性三方面全面升级：

| 维度 | 相比 VoidMei |
|---|---|
| **性能** | 实测 CPU 占用率**降至 VoidMei 的约 1/3**，内存占用**降至约 1/4**（同等数据刷新率下） |
| **功能** | 两种 HUD 样式（紧凑面板 / 圆环）与鼠标拖拽布局；飞行记录 `.wpr` + 3D 回放 + ACMI/CSV 导出；按机型的性能曲线与喷气机 EM 能量机动图；数据链；15 种界面语言 |
| **安全性** | 只读 8111 端口、不注入进程、不读写游戏内存；本地 HTTP 服务只绑 `127.0.0.1`（控制通道另带令牌）；上传体积、Content-Type、请求来源与路径穿越都有校验 |

> 用惯了 VoidMei 的话可以直接换过来：日常操作都收在控制台里（配置 / 飞行模型 / 回放页签），
> 配置项、语音包与界面语言的组织方式也大体对应。

## 这是什么

```
战争雷霆（游戏自己开放的 8111 端口）
      │  只读读取，不碰游戏
      ▼
   WP8F：解析数据 → 结合飞机的飞行模型算出限制值与告警
      ├──► 屏幕上的透明 HUD（三种模式：关闭 / 紧凑面板 / 圆环）
      ├──► 飞行记录（每局一个文件，可回放、可导出）
      └──► 数据链（可选）：和同局队友互相看见
控制台（双击 wp8f-gui.exe）负责开关、配置、曲线、回放与更新。
```

能做什么：

- 实时飞行数据 HUD，三种模式可选（**关闭 / MiniHUD 紧凑面板 / 圆环 HUD**），面板位置可以用鼠标拖
- 表速/马赫两级超速告警、攻角与过载告警（屏幕上闪烁的 ×）、语音告警
- F-18 风格机动告警声（可以单独关掉）
- 每局自动记录飞行数据，控制台里回放轨迹、导出 TacView ACMI / CSV
- 按机型查气动/发动机性能曲线（推力、功率、盘旋率……）
- 界面 15 种语言；HUD 标签可选中文/英文
- 数据链：和同局队友在地图上互相看见（需要一台有公网 IP 的机器，见下）

## 安装

**Windows 10/11，解压即用，不需要装任何东西。**

1. 解压 `wp8f-<日期>.zip` 到任意目录（路径别太深，别放在中文目录下也行，但纯英文最稳）
2. 双击 `wp8f-gui.exe`
3. 第一次运行 Windows 可能弹「已保护你的电脑」→ 点**更多信息 → 仍要运行**
   （exe 没有代码签名，杀毒软件也可能误报，加白名单即可）

## 快速上手

1. 启动战争雷霆，**进入一局战斗或试飞**（在机库里 8111 端口可能没有数据）
2. 回到控制台，点右下角的「**开 始**」
3. 屏幕上出现透明 HUD。控制台窗口可以关掉，程序会留在**右下角托盘**里
   （托盘图标右键：显示窗口 / 退出；左键单击也能叫回窗口）

不想开游戏？点「**预 览**」——它自带一个模拟服务端，会给出假的飞行数据，
用来调 HUD 布局、看界面长什么样最方便。

**调面板位置**：点「预 览」进去后 HUD 处于拖拽模式，直接用鼠标把面板拖到想要的位置
（拖完自动记住）；位置调好后点「开 始」跑真实数据即可。

## 控制台里有什么

| 页签 | 干什么 |
|---|---|
| 配置 | 改一切设置：HUD 样式、面板位置与颜色、告警、记录、数据链、界面语言。改完自动保存 |
| 飞行模型 | 按机型看性能曲线（推力/功率/盘旋率等），喷气机还有 **EM 能量机动图**；顶部显示本地飞机数据的版本，并可一键更新 |
| 回放 | 看飞行记录：3D 轨迹、遥测曲线、地图底面，导出 ACMI / CSV |
| 导弹 | 离线导弹仿真（可选子模块） |

改 HUD 面板位置：点「预 览」进入拖拽模式，用鼠标把面板拖到想要的位置（会自动记住）。

## 数据从哪来（重要）

WP8F 用到两类数据：

1. **实时飞行数据** —— 来自游戏自己开放的本地端口 `127.0.0.1:8111`。
   **只读**：不修改游戏、不注入进程、不读写游戏内存。
2. **飞机性能数据**（气动、发动机、结构限制、武器等）—— 来自网络公开的拆包数据库
   [War-Thunder-Datamine](https://github.com/gszabi99/War-Thunder-Datamine)，
   本工具只是读取这些已经公开的数据文件（`resource\data`）。

> ⚠️ **声明**：对游戏客户端进行拆包**本身可能违反游戏的最终用户许可协议（EULA）**。
> 所用的性能数据来自上述第三方公开数据库，与拆包行为无关。
> 是否使用这些数据以及由此产生的后果，请自行判断与承担。

## 数据链（可选）：和队友互相看见

数据链让**同一局**的玩家在地图上互相看到对方（位置、机型、速度、高度、航向）。让不喜欢开麦的玩家也能灵能通信。
默认关闭。它需要一台**有公网 IP** 的机器跑服务端 —— 会开服的人跑一个，其他人填上地址即可。

### 一、服务端（有公网 IP 的那台，谁都能跑）

包里自带两个平台的版本：

```bat
:: Windows
binary\datalink-server.exe --port 2887 --key 换成你自己的密钥
```
```bash
# Linux
./binary/datalink-server --port 2887 --key 换成你自己的密钥
```

- 默认监听 `0.0.0.0:2887`（UDP）——记得在**防火墙/云安全组**放行这个端口
- `--key` 是链路密钥，**服务端和所有客户端必须完全一致**，否则互相看不见
- 密钥只是异或混淆，**不要用你在别处用的真密码**
- 其他参数：`--hz`（应答限频，默认 4）、`--timeout`（多久收不到消息就把对方移除，默认 5 秒）、
  `--max-tracks`（一次最多带多少架，默认 12）；`--help` 看全部

### 二、客户端（每个人自己）

控制台 →「配置」页签 → 找到数据链那几项（也可以直接编辑 `config\*.json`）：

| 设置 | 填什么 |
|---|---|
| 启用 | 打开 |
| 服务器 / 端口 | 服务端的 IP 与端口（默认 `127.0.0.1:2887`） |
| 密钥 | 与服务端一致 |
| 对局编号 | 1–255 里挑一个数字：**只有编号相同的人互相可见**，和队友约定好 |
| 上报频率 | 每秒发几次自己的状态，默认 4 |

打开后：地图上出现**绿色三角**（友军，箭头方向 = 它机头朝向）和机型标签，
右侧「友军」面板列出机型/表速/高度/航向/距离/区域格。对方离线 5 秒后自动消失。

### 三、连不上时怎么查

包里带了测试客户端，先用它确认「服务端通不通」：

```bat
binary\datalink-test-client.exe --server <IP:端口> --session 1 --key 你的密钥
```

它会发送合成的假数据，并把收到的数据打印出来。**能打印出别人的数据 = 链路是通的**，
问题在客户端配置（密钥/编号/防火墙）；什么都不打印 = 服务端没通或端口没放行。

## 常见问题

**Q：双击没反应，或被 SmartScreen / 杀毒软件拦住？**
程序没有代码签名，Windows 和杀毒软件会保守拦截。点「更多信息 → 仍要运行」，
或把整个解压目录加进杀毒软件白名单。

**Q：HUD 一直不显示 / 提示连不上 8111？**
先确认游戏已经**进入对局或试飞**（在机库、菜单里 8111 端口常常没有数据）。
确认没问题后，在控制台点「开始」，几秒内 HUD 就会出现。

**Q：HUD 挡视线 / 想换个位置？**
HUD 有三种模式（关闭 / MiniHUD / 圆环 HUD），在配置页的「HUD 类型」里三选一；
位置点「预 览」后用鼠标拖（会自动记住）。
面板被拖到屏幕外面时，可以在配置页恢复默认位置。

**Q：飞行记录在哪？想删掉？**
`logs\` 目录里，一局一个 `.wpr` 文件。回放页签能看到列表；不需要就整个删掉。

**Q：界面语言 / HUD 上的文字语言怎么改？**
界面语言在控制台左下角；HUD 标签语言在配置页的「HUD 语言」一项（中文 / 英文）。

**Q：会不会影响游戏、会不会被封号？**
WP8F 只读取游戏自己开放的 `127.0.0.1:8111` 端口，不注入进程、不改内存、不发包给游戏。
但**是否使用第三方工具由你自行判断和承担** —— 请遵守游戏规则与 EULA。
